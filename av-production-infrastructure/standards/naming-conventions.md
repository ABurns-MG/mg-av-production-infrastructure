# Naming Conventions

## Purpose

Consistent naming prevents confusion across systems, rooms, and documentation.

## Format

```
[LOCATION]-[SYSTEM]-[TYPE]-[IDENTIFIER]
```

## Examples

| Name | Meaning |
|------|---------|
| MS-AUD-DANTE-CH61 | Main Sanctuary, Audio, Dante Channel 61 |
| MS-VID-CAM1 | Main Sanctuary, Video, Camera 1 |
| MS-VID-SDI-OUT1 | Main Sanctuary, Video, SDI Output 1 |
| EVT-VID-CAM2 | Event Center, Video, Camera 2 |
| KM-AUD-XLR-CH01 | Kids Ministry, Audio, XLR Channel 1 |
| YTH-LTG-DMX-U01 | Youth, Lighting, DMX Universe 1 |

## Location Codes

| Code | Location |
|------|----------|
| MS | Main Sanctuary |
| KM | Kids Ministry |
| YTH | Youth |
| EVT | Event Center |

## System Codes

| Code | System |
|------|--------|
| AUD | Audio |
| VID | Video |
| LTG | Lighting |
| BRD | Broadcast |
| IMG | IMAG |

## Type Codes

| Code | Type |
|------|------|
| DANTE | Dante network audio |
| SDI | SDI video |
| XLR | Analog audio |
| DMX | DMX lighting |
| NDI | NDI video |
| HDMI | HDMI video |

## Rules

1. Always use uppercase
2. Use hyphens as separators
3. Channel numbers are zero-padded (CH01, not CH1)
4. Be specific enough to be unambiguous
